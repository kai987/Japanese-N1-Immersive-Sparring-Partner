# 学習記録の保存・同期・バックアップ

学習記録は現在のブラウザー内に保存します。アカウントやサーバーへの送信はなく、別の端末・ブラウザーへの自動同期も行いません。

## 既存データとの互換性

従来の保存キーと値の形式は維持しています。

| キー | 内容 |
| --- | --- |
| `n1-progress` | 語彙・文法の状態、元の選択肢番号による回答、回答履歴、学習日。現行形式はversion 2 |
| `n1-completed-lessons` | 日付ごとの読了状態 |
| `n1-live-reactions-progress-v1` | 直播ノートの知識グループごとの状態。version 1 |
| `n1-theme` | `light`／`dark` |

旧形式の有効なマーク・回答は読み込み時に移行します。現在の教材一覧にない有効なIDも捨てません。日時がない旧回答は日時不明の履歴として保持し、架空の日時や固定の連続学習日数を追加しません。

## 複数タブでの学習

各操作は、画面に表示していた状態からの変更差分として、`n1-record-journal-v1:` で始まる固有のローカル操作ログにも保存します。別のタブが持つ古い全体スナップショットで、そのまま記録を置き換えることはありません。

- 同じページ内では共有ストアを使用し、別のタブからの変更はブラウザーのstorageイベントなどで反映します。
- 異なる語彙・文法・読了・直播グループの操作は組み合わせて保持します。同じ項目は後の操作を優先し、完全に同時の場合も時刻と操作IDで全タブの順序をそろえます。
- 「習得済み」を外す、読了を解除するなどの明示的な操作も反映します。
- 学習日は重複をまとめて保持します。回答履歴は同時に行った回答や以前の日時不明の回答を残し、同じ操作ログの再適用で履歴を増殖させません。
- 壊れた操作や、状態・日付・回答形式が不正な操作は適用対象から除外し、読み取れる既存の記録と他の有効な操作を保持します。

操作ログは、同時書き込みで表側の保存値が一時的に古くなった場合の復元にも使います。安全な全タブ共通のチェックポイントなしに削除・圧縮すると復元を壊すため、現時点では自動削除しません。容量のためにこのログだけを手動削除することも避けてください。

更新前の古いプログラムを開いたままのタブは、新しい操作ログに参加できません。公開更新後は、開いている学習タブを一度再読み込みしてください。

## 保存に失敗した場合

容量不足やブラウザーの制限がある場合も、現在のページ内では学習と変更を保持し、保存失敗を表示します。「保存を再試行」で、保存済みの他タブの操作と組み合わせて書き込み直します。操作ログだけ保存できた場合も、そこから記録を再構成します。

すべての書き込みが拒否された変更は、ページ内のメモリーにしか残りません。ページを閉じる・再読み込みする前に、保存の再試行かエクスポートを行ってください。エクスポートには、このページが保持している未保存の有効な記録も含めます。

## ファイルへのエクスポートと取り込み

「学習履歴」の「学習記録のバックアップ」から操作します。

1. **学習記録をエクスポート**：上記4種類の記録をJSONファイルとして端末に保存します。音声ファイル、秘密情報、他のサイトのデータや操作ログは含めません。
2. **学習記録ファイルを選択**：このアプリの識別子・対応バージョン・許可された保存キー・値の形式を検証します。2 MBを超えるファイル、不正なJSON、破損した値や未対応形式は、記録を変更する前に拒否します。
3. **取り込み内容を確認**：語彙・文法・読解・読了・直播ノートの件数を表示します。確認ボタンを押すまでは取り込みません。
4. **確認して取り込む**：現在のマーク、現在の回答、明示的な解除、表示テーマを優先し、足りない項目・回答履歴・学習日を追加します。既存の記録を削除せず、同じファイルの再取り込みで履歴を増殖させません。

取り込み中に一部の保存が失敗した場合は、その状態を表示します。元のファイルと現在の記録を保持し、保存を再試行してから再度取り込めます。ファイルはブラウザー内でのみ読み書きし、外部へアップロードしません。
