# 直播笔记的稳定标识与音频引用

每个学习单元、知识组、词条和例句都有独立的稳定 ID。ID 用于界面渲染和内容校验；学习标记仍按原知识组 ID 保存，旧记录无需重置。

- 已有词条和例句的 ID 已写入数据文件。即使 ID 中包含数字，也不要因为重新排序而重编号。
- 新词条和例句应分配新的、全局唯一的小写字母／数字／连字符 ID。显示顺序只由数组顺序决定。
- 新内容的音频引用使用稳定 ID，不再使用词条文字或当前数组位置。
- legacyAudioRef 是已有内容的兼容别名。它固定了旧的 entry/原文字 或 example/原序号，必须保留；移动内容时不能按新位置重写它。
- 修订中文说明、分类或排列不影响日文录音。更改已发布的日文发话时，应新增内容身份和对应引用，保留旧录音与快照绑定；不要把旧引用改绑到另一段话。

validateLiveIdentities 在模块导入／构建时检查唯一 ID、必要字段与音频引用别名。单元计数由实际条目和补充分组自动计算。

播放器使用构建时生成的精简索引，只包含播放地址、提供方、时长和公开的待配音数量。完整的 SHA-256、字节数、来源清单与发布验证保留在原文件中；此优化不改变已发布录音或上传验证。
